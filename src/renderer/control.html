直播姬里建议加两个浏览器源：一个填上面「歌词叠加层」地址、尺寸就设成你想要的歌词区域 （比如 1280×200）；另一个填「信息卡片」地址、尺寸贴合卡片（约 320×100）。 浏览器源的框就是页面尺寸 —— 一个源里塞两样东西，框必然比各自都大得多；分开就刚刚好。

直播状态

未直播
切到「直播中」时，「已保存播放列表」作为闲时歌单 —— 当前列表放空后自动接着放； 有人点歌时它会立刻让位给点歌队列。
弹幕只在「直播中」时接收与执行：切到直播中会自动连弹幕（按 `bilibili.autoConnect`）， 切回「未直播」立即停止接收弹幕，点歌/切歌这类指令也不再有反应。
平时想试歌？用下面的点歌框（那条路不经过弹幕，什么时候都能用）， 或用「注入弹幕」验证指令链路。
「已保存播放列表」是手动维护的：想留哪首就点它旁边的「加入已保存」， 下播不会自动往里写（也不会清掉你已有的）。

叠加层预览

预览窗是透明无边框的，会盖在其它窗口之上；拖动顶部工具条可移动位置，Esc 或「关闭预览」可收起。

点歌 / 检索

要放本地歌 → 用下方「本地音乐」卡片里的 打开音乐文件… / 打开音乐文件夹…（和点歌一样排进当前播放列表）。

歌单导入（网易云）

支持纯数字 ID、网页链接、手机分享短链（163cn.tv/…）。导入时自动过一遍黑名单。
默认导入到「已保存播放列表」（不打断正在播/正在排的点歌）；想立刻整单排进当前队列，用右边那个按钮。

弹幕点歌

弹幕通道（切换后立即重连）：只有在「直播中」状态才会接收弹幕 —— 未直播时连接会被停掉， 点歌请用上面的点歌框。
开放平台凭据（在 open-live.bilibili.com 拿： 项目概览里有项目ID，身份码在互动应用中心 / 直播中心可获取）
⚠️ 弹幕消息类型（DM）需要提前向 B站运营申请开通，否则长连建得起来但收不到弹幕 （QQ 群 642908379 或邮件 live-open@bilibili.com）。
指令：点歌 歌名 / 点歌 ID 歌曲ID / 点歌 本地 歌名 / 点歌 b站 关键词 / 点播 BV号（裸 BV 号 / 链接 / 小写 bv 都能自动认） / 切歌 / 撤歌 2 / 我的 / 队列
以下两行是 B站账号登录 —— 只用来解锁「视频字幕当歌词」，与上面的直播间连接无关（连直播间请用上面的「连接」+ 房间号）。
B站字幕（CC/AI）需要登录：未登录时接口一律返回空列表，视频歌词只能回落到「按标题匹配网易云」，冷门曲（游戏/同人 OST）大多匹配不到。

点歌设置

切歌权限：点歌本人、房管、主播 都可以用弹幕指令把正在放的歌切走；观众切别人的歌会被拒。取消勾选"本人可切"后，只有房管/主播能切。规则改完立即生效。

当前播放列表

点歌与「打开本地文件」一视同仁排队，按顺序播放。第一行是正在播放的那首；播完会移到「已播放」（手动切走的也算播完）。列表长了可以在框内滚动，不必翻整页。
    每项可「置顶」或直接拉黑（拉黑会同时把它撤下队列）

      内容来自：歌单导入（默认落这里）、列表项上的「加入已保存」、以及下面的来源按钮。
      未直播时可直接播放
        无论来源，一视同仁汇入这个列表（歌单导入已在上面那个卡片里）

        闲时歌单

        闲时播放的内容就是「已保存播放列表」 —— 不管歌来自网易云歌单、本地曲库还是收藏， 都先「加入已保存」，再由这一个列表统一充当闲时歌单。队列空了就自动接着播，点歌一进来就会盖过它。

        在线缓存

        当前目录：—
        歌曲音频、封面、歌词都放在这个目录下面。默认在程序目录里， 不会写到 C 盘；想放别的大盘上就换一个目录（换目录不会删除旧文件）。
        首次播放仍走远端直链（不卡声音），后台落盘；下次点同一首直接读本地， 不受直链过期影响。45 秒试听片段不会缓存。
        下面每一条都可以单独 删缓存；「已播放」「已保存」列表里的每一行也都有 缓存 / 删缓存 按钮（已缓存的会显示绿色角标）。

          测试中心 / 自检

          命令行也能跑：node tools\headless.js --testcenter（加 --net 含联网）。

          网易云登录（会员曲必需）

          登录状态未知 —— 点「检测登录状态」核验
          扫码后自动保存 cookie。没登录时会员曲只能放 45 秒试听片段。
          「打开登录窗」会弹出一个真实浏览器窗口，登录一次即可：会话会持久保存， 既是登录手段，也是接口被掐时的取流退路。

          播放核心 / 输出设备

          当前：系统默认
          把输出选到 VoiceMeeter 的音乐通道（如 Voicemeeter Aux Input / CABLE Input），好处是游戏声与音乐声互不干扰。选择会被记住，重启后自动恢复。

          歌词叠加层

          默认不勾：字号就是上面滑块的值 —— 配合「把浏览器源的框设成组件尺寸」用， 框设多大、字幕就正好占多大，所见即所得。
          勾上则按源高等比缩放（1080p 基准），适合把源铺满整个画面的用法。
          —
          「歌词底板」给字幕垫一条半透明色带 —— 文字融进画面时（比如浅青高亮落在青蓝色游戏画面上） 这是最稳的一招，任意背景都看得清。0 = 关；35~55 最常用。
          垫在字幕底下那条色带的颜色
          三个颜色各管一块，互不影响：正文色 = 非当前行 （注意当前行不受它影响）；高亮色 = 正在唱的这一句，含它的翻译行； 描边色 = 所有歌词文字的描边（粗细由下面的「描边宽」定）。
          显示行数：只显示当前这一句 —— 勾了「显示翻译」就是「原文 + 译文」两行， 不勾则只有一行原文。（翻译字号与原文一致）
          源的框高度按 1 行 ≈ 66px、2 行 ≈ 120px 填最贴合。
          毫秒，正值=歌词延后

          黑名单 / 审核
